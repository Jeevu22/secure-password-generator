Security Principles
🔢 Length Beats Complexity

A 20-char lowercase phrase >> "Tr0ub4dor&3". Every character multiplies the search space exponentially.

🎯 Patterns Over Rules

Attackers use pattern matching. Dictionary + l33t + year = cracked in seconds. True randomness wins.

🔑 One Per Site

One breach = every shared account exposed. Use a password manager for unique passwords everywhere.

💬 Passphrases Work

4 random words (~50+ bits entropy) > 8-char complex password. Easier to remember, harder to crack.

🚫 No Forced Rotation

Mandatory changes lead to P@ssword1 → P@ssword2. Change only on breach evidence (NIST 800-63B).

🔎 Check Breaches

A strong password already leaked is useless. Verify against Have I Been Pwned regularly.

🛡️ MFA Everywhere

One password = one factor. A weak password + MFA >> a strong password alone.

🗄️ Use a Password Manager

The only way to have strong, unique passwords everywhere. Trust the tool, not your memory.
